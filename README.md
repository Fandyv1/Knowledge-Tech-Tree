# Knowledge-Tech-Tree（知乎科技树）

Help people who want to learn knowledge better understand what they should study.

帮助希望学习知识的人更清楚地了解自己应该学什么。

## 简介

以「科技树」的形式组织知识点与学习路径，让学习者看清知识之间的依赖关系和推荐的学习顺序。
